# Python for Data Engineering

This section covers **Python programming fundamentals and essential concepts required for Data Engineering**.
The goal is to build a strong Python foundation before moving into tools such as **Pandas, PySpark, Airflow, Kafka, and ETL pipelines**.

## 🐍 Python Setup

### 1. Install Python

Download and install Python from the official website:

**Python:** https://www.python.org/downloads/

During installation on Windows, make sure to enable:

```text
Add Python.exe to PATH
```

### 2. Verify Installation

Open Command Prompt / Terminal and run:

```bash
python --version
```

or:

```bash
python3 --version
```

Check pip:

```bash
pip --version
```

### 3. Create a Virtual Environment

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Activate it on Linux/macOS:

```bash
source venv/bin/activate
```

To deactivate:

```bash
deactivate
```

### 4. Install Required Packages

For the initial Python learning stage:

```bash
pip install pandas numpy requests
```

Additional packages will be installed as required while progressing through the Data Engineering roadmap.
