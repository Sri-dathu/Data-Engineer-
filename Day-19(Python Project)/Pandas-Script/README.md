# E-Commerce Data Analysis

## About the Project

This project is a beginner-level data analysis project built using Python and Pandas.
It demonstrates how to read, clean, transform, summarize, and analyze an e-commerce dataset.

## Project Workflow

```text
Read Data
    ↓
Inspect Data
    ↓
Clean Data
    ↓
Transform Data
    ↓
Aggregate Data
    ↓
GroupBy Analysis
    ↓
Export Results
