# SQL Business Analytics – AdventureWorks

A Business Analytics project using **AdventureWorks2022** and **Microsoft SQL Server** to analyze sales, customers, products, employees, territories, and inventory.

## Dataset

This project uses the official **AdventureWorks2022** sample database provided by Microsoft.

**Dataset:**  
https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure

## Project Sections

### 1. Introduction
Introduces the Adventure Works business scenario, dataset, project objective, and tools used.

### 2. Database Overview
Provides an overview of the AdventureWorks database, its schemas, core tables, and relationships.

### 3. Business Problem Statement
Defines the real-world business problems and analytical questions that management wants to answer.

### 4. Sales Analysis
Analyzes revenue, sales trends, territories, salespersons, order values, and year-over-year performance.

### 5. Customer Analysis
Analyzes customer purchasing behavior, lifetime revenue, number of orders, and average order value.

### 6. Product Analysis
Identifies best-selling products, category performance, and top-performing products within each category.

### 7. Employee & Territory Analysis
Evaluates salesperson performance and compares sales performance across different territories.

### 8. Inventory Analysis
Analyzes inventory levels, identifies products below reorder levels, and evaluates inventory value.

### 9. Executive Dashboard
Provides key business KPIs such as revenue, orders, customers, average order value, and top performers.

### 10. Advanced SQL Concepts
Demonstrates practical SQL techniques including CTEs, Views, Stored Procedures, Functions, and Temporary Tables.
